# SKILL.md 작성 규칙
- frontmatter에는 name, description만 포함
- name과 description은 lowercase
- body에는 "when to use"를 길게 쓰지 말고, 트리거 정보는 description에 반영
- body는 명령형/절차형으로 작성
- 장황한 일반론보다 구체적이고 재사용 가능한 지침 중심으로 작성
- 필요 시 예시 출력 형식도 포함
