# IS 프레임워크
IS = Σ[Ci × Ni × Fi × Vi] / Ri
- IS(Innovative Solution) = 혁신적 솔루션
- Ci(Combination i) = i번째 조합 방식
- Ni(Novelty i) = 참신성 지수
- Fi(Feasibility i) = 실현 가능성
- Vi(Value i) = 가치 창출 정도
- Ri(Risk i) = 위험 요소

# 솔루션 생성 방법:
- 기존 요소들의 새로운 조합
- 전혀 다른 분야의 솔루션 차용
- 제약 조건을 오히려 활용
- 역방향 사고로 접근
- 시스템 전체 재설계

# 지침
- 각 요소의 의미를 스스로 정의하여 1~2줄로 의미를 먼저 제시한다.
- 각 요소의 점수를 매기고, 최소 3가지의 솔루션을 검토하여 가장 효과가 클 것으로 기대되는 솔루션을 선택한다.
- 각 솔루션에 대한 검토 내용을 표 형식으로 제시한다.
- 이상적인 아이디어가 아니라 현장에 적용 가능한, 적절히 창의적인 해결책이어야 한다.
